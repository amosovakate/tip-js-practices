## Запуск в терминале (Node.js)

Файл `practice-01/js/hello.js` запущен командой:

    node practice-01/js/hello.js

Вывод появился в терминале.

## Запуск в браузере

Файл `practice-01/index.html` открыт в браузере
Вывод появился во вкладке Console инструментов разработчика (F12),
а не на самой странице.
