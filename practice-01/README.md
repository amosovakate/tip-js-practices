Файл `practice-01/js/hello.js` запущен командой:

    node practice-01/js/hello.js

Вывод появился в терминале.

## Задание 2. Исследование типов и преобразований

### 1. `"8" + 2`
- Ожидание до запуска: `"82"`
- Фактическое значение: `82`
- Тип результата: string
- Объяснение: если один из операндов строка, оператор `+` выполняет конкатенацию. Число 2 превращается в строку `"2"` и присоединяется к `"8"`.

### 2. `"8" - 2`
- Ожидание до запуска: `6`
- Фактическое значение: `6`
- Тип результата: number
- Объяснение: оператор `-` работает только с числами, поэтому строка `"8"` преобразуется в число 8.

### 3. `Number("8") + 2`
- Ожидание до запуска: `10`
- Фактическое значение: `10`
- Тип результата: number
- Объяснение: строка явно преобразована в число, затем выполнено обычное сложение.

### 4. `"12" > "3"`
- Ожидание до запуска: `false`
- Фактическое значение: `false`
- Тип результата: boolean
- Объяснение: две строки сравниваются посимвольно, а не как числа. Первый символ `"1"` меньше `"3"`, поэтому `"12"` меньше `"3"`.

### 5. `12 === "12"`
- Ожидание до запуска: `false`
- Фактическое значение: `false`
- Тип результата: boolean
- Объяснение: строгое равенство не приводит типы. Число и строка это разные типы, поэтому значения не равны.

### 6. `Number("")`
- Ожидание до запуска: `0`
- Фактическое значение: `0`
- Тип результата: number
- Объяснение: пустая строка при преобразовании в число даёт 0.

### 7. `Number("text")`
- Ожидание до запуска: `NaN`
- Фактическое значение: `NaN`
- Тип результата: number
- Объяснение: текст нельзя преобразовать в число, поэтому получается `NaN` («не число»). Сам `NaN` имеет тип number.

### 8. `Boolean("false")`
- Ожидание до запуска: `true`
- Фактическое значение: `true`
- Тип результата: boolean
- Объяснение: любая непустая строка приводится к `true`, независимо от содержимого. Ложной является только пустая строка `""`.

### 9. `typeof null`
- Ожидание до запуска: `"object"`
- Фактическое значение: `"object"`
- Тип результата: string
- Объяснение: это историческая особенность JavaScript. `typeof null` возвращает `"object"`, хотя `null` является примитивом. Оператор `typeof` всегда возвращает строку.

### 10. `typeof NaN`
- Ожидание до запуска: `"number"`
- Фактическое значение: `"number"`
- Тип результата: string
- Объяснение: `NaN` относится к типу number. Результат `typeof` это строка.
